# 📝 Bài 04 — Dự án tổng hợp: "Sổ tay chi tiêu"

Mục tiêu: dùng Tab Code xây một web app nhỏ quản lý chi tiêu, áp dụng toàn bộ kiến thức.

## Giai đoạn 1 — Cơ bản
- [ ] Yêu cầu: *"Tạo app web HTML/CSS/JS thuần: nhập khoản chi (tên, số tiền, ngày), hiển thị danh sách và tổng tiền, lưu bằng localStorage."*
- [ ] Review diff, góp ý giao diện ít nhất 2 lần.
- [ ] Tạo PR và merge.

## Giai đoạn 2 — Trung cấp
- [ ] `/init` để tạo CLAUDE.md, thêm quy ước: "định dạng tiền theo VNĐ (vd. 150.000 ₫)".
- [ ] Dùng Plan mode cho tính năng **lọc theo tháng + biểu đồ theo danh mục**; duyệt kế hoạch rồi cho làm.
- [ ] Yêu cầu thêm test (vd. với Vitest/Jest) cho hàm tính tổng và định dạng tiền.
- [ ] Chạy `/code-review`, sửa các phát hiện hợp lý.

## Giai đoạn 3 — Nâng cao
- [ ] Thêm `SessionStart` hook chạy `npm install`.
- [ ] Thêm GitHub Actions chạy test cho mỗi PR.
- [ ] Viết skill `them-tinh-nang` mô tả quy trình chuẩn: kế hoạch → code → test → PR.
- [ ] Mở PR mới, bật theo dõi PR để Claude tự xử lý CI và review.
