# Học tập Tab Code (Claude Code) — từ cơ bản đến nâng cao

Tab **Code** trong ứng dụng Claude (web, desktop, điện thoại) chính là **Claude Code**: một "lập trình viên AI" làm việc trực tiếp trên kho mã (repository) của bạn — đọc file, chạy lệnh, sửa code, commit, push và tạo Pull Request trên GitHub.

Repo này là giáo trình tự học, chia theo 3 cấp độ. Mỗi bài có lý thuyết, ví dụ câu lệnh mẫu (prompt) và bài tập.

| Cấp độ | Bài học | Bạn sẽ làm được |
|---|---|---|
| 🟢 Cơ bản | [01 — Làm quen](bai-hoc/01-co-ban.md) | Mở phiên làm việc, ra yêu cầu, đọc kết quả, review thay đổi |
| 🟡 Trung cấp | [02 — Làm việc hiệu quả](bai-hoc/02-trung-cap.md) | CLAUDE.md, lệnh `/`, Plan mode, quản lý ngữ cảnh, quy trình Git/PR |
| 🔴 Nâng cao | [03 — Tự động hoá & mở rộng](bai-hoc/03-nang-cao.md) | Môi trường cloud, setup script, hooks, skills, subagents, MCP, theo dõi PR |
| 📝 Thực hành | [04 — Bài tập tổng hợp](bai-hoc/04-bai-tap.md) | Dự án nhỏ áp dụng toàn bộ kiến thức |

## Cách học gợi ý

1. Đọc lần lượt từng bài, **làm bài tập ngay trong chính repo này** (nó đang trống — rất hợp để thử nghiệm).
2. Mỗi lần thử, hãy đọc kỹ những gì Claude làm (lệnh nó chạy, file nó sửa) — đó là cách học nhanh nhất.
3. Khi chưa chắc, hỏi thẳng Claude: *"Giải thích cho tôi bạn vừa làm gì và tại sao"*.

> Lưu ý: Tính năng của Claude Code cập nhật liên tục. Tài liệu chính thức: https://code.claude.com/docs
